# ZNAK Continuity Bootstrap — READ FIRST

Before any material work in this repository:

1. Read the private canonical continuity file: `HumbleDrummer/CHECPOINT/LATEST.md`.
2. Read the newest relevant checkpoint comment(s) in `HumbleDrummer/CHECPOINT#4`.
3. Verify material claims against the current repository / CI / source before acting.
4. Apply every active hard gate in `LATEST.md`.
5. Only then modify code, configuration, issues, PRs, deployments or external systems.

Continuity rules:
- `CHECKPOINT != TRUTH`
- `RETRIEVED != CURRENTLY VALID`
- `DECISION != AUTHORIZATION`
- `AUTHORIZED != EXECUTED`

After material work, append one concise checkpoint to `CHECPOINT#4`:
`changed / verified / blocked / hard_gates / next / refs`.

Never put secrets, passwords, API keys, tokens or private keys in the checkpoint.

If the private CHECPOINT repository is unavailable, do not invent continuity from stale repository notes. Read-only inspection may continue; paid, destructive, deployment, credential, merge-to-production or irreversible actions require current evidence and explicit authority.
